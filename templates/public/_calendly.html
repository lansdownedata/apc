{% comment %} Calendly popup assets plus the bridge that gets an invitee OUT of the iframe. The event type's "Redirect to an external site" setting navigates the POPUP's iframe, not the page behind it — on its own the visitor ends up on our thanks page inside a modal, still on whatever page they started from. Calendly posts `calendly.event_scheduled` to the parent window, so the parent does the navigation. Consequence, by design: the parent cannot read the iframe's cross-origin URL, so the popup path lands on the generic thanks page while direct-link traffic gets the personalized one. schedule_thanks handles both. The origin check is not optional — this listener runs on every public page, and window.postMessage can be called by any frame on the page. {% endcomment %}
