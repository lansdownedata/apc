{% comment %} Reusable right-side drawer. Unlike the modal (a global $store), a drawer is a per-page surface, so it takes a scoped x-data. Include once per page that needs one: {% include "components/drawer.html" with drawer_title="Assign trip" %} Open it from anywhere on the page: $dispatch('drawer-open', {url: '/portal/…/panel/'}) The fragment at `url` is fetched and injected — the drawer never knows what it holds. An optional `title` in the detail heads that one open (History); without one the heading is `drawer_title`, so every other caller keeps its own. The header is a fixed h-16, so a fragment's sticky element can sit flush under it at top-16. {% endcomment %}
